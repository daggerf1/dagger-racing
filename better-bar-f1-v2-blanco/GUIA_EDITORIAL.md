# GUÍA EDITORIAL — DAGGER RACING NEWS

## 1. Navegación de noticias

Todas las noticias deben mostrar:

INICIO / REFERENCIA PRINCIPAL

La referencia será el piloto, escudería, organismo o tema protagonista.

Ejemplos:
- INICIO / NORRIS
- INICIO / PIASTRI
- INICIO / MCLAREN
- INICIO / MERCEDES
- INICIO / FIA

La referencia NO debe tomarse automáticamente de la subcategoría.

La subcategoría (paddock, crónica, etc.) sirve para clasificar
la noticia, no para definir su navegación.

Cuando exista una página de piloto, equipo u organismo,
la referencia debe enlazar a esa página.

## 2. Créditos fotográficos

Todas las fotografías deben llevar créditos debajo de la imagen
dentro del artículo, no superpuestos en las tarjetas de portada.

Formato:

Fotografía original: AUTOR / FUENTE · LICENCIA ·
Edición gráfica mediante IA: Dagger Racing News.
Imagen modificada respecto al original.

Original: ENLACE · Licencia: ENLACE

La autoría, fuente y licencia deben corresponder a cada fotografía.

Solo mencionar edición mediante IA cuando realmente se haya
utilizado inteligencia artificial para modificar la imagen.

No inventar autores, fuentes ni licencias.

## 3. Reglas de publicación

- Las noticias se guardan en src/content/noticias/.
- Las fotografías se guardan en public/.
- No modificar otras noticias al publicar una nueva.
- No modificar el diseño ni el menú sin autorización.
- Ejecutar npm run build antes de publicar.
- Subir únicamente los archivos correspondientes a cada cambio.
